# TubeJoint for Autodesk Inventor 2027

Надстройка для создания редактируемых соединений «шип-паз» между трубами Frame Generator в Autodesk Inventor 2027.

## Возможности

- создание одного или двух противоположных шипов и пазов;
- выбор сторон соединения и поворот расположения на 90°;
- настройка размеров, зазора и дополнительного отверстия;
- предварительный просмотр и 3D-манипуляторы;
- поддержка профилей из линий, дуг и сплайнов;
- сохранение штатных операций Frame Generator Trim, Miter и Notch;
- распознавание прямых круглых и профильных труб по геометрии;
- заполнение iProperties и нормализация центра/поворота трубы относительно XYZ.

Профили хранятся в редактируемом шаблоне Inventor. При первом запуске создаётся простой базовый шаблон.

## Требования

- Autodesk Inventor Professional 2027;
- Windows 10 или Windows 11;
- .NET 8 SDK для сборки.

## Сборка и установка

Закройте Inventor и выполните в PowerShell из корня проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

После запуска Inventor команда находится на вкладке **Design** в панели **Шип-паз труб**.

Окно параметров соединения открывается в штатном `DockableWindow`, использует
цвета текущей темы Inventor и по умолчанию имеет узкую вертикальную компоновку.
После ручного изменения размера или закрепления Inventor восстанавливает выбранное
пользователем состояние окна при следующем запуске команды.

Вместо встроенных пресетов пользователь настраивает размеры и опции текущего
соединения, затем сохраняет их под своим именем кнопкой `+`. Меню с шестерёнкой
позволяет обновить, переименовать или удалить пресет, выбрать сортировку и режим
по умолчанию для нового соединения. Пресет сохраняет также выбранный вариант
эскиза шипа-паза. Второй селектор показывает все IPT из папки TubeJoint `Templates`;
его кнопка `+` создаёт копию текущего варианта, а кнопка редактирования открывает
выбранный IPT в Inventor. Исходный `StandardSideTenonSlot_v6.ipt` сохраняется как
совместимый базовый профиль и автоматически не перерисовывается.

## Распознавание и нормализация трубы

Команда **Подготовить трубы** доступна в сборке на панели **Шип-паз труб** и в
открытой детали на вкладке **Model**, панель **Подготовка труб**. Она работает с
деталью, содержащей одно прямое полое solid-тело:

- определяет круглое либо прямоугольное сечение, габариты, толщину стенки и длину;
- заполняет Description и Stock Number, а также пользовательские `TubeJoint.*` iProperties;
- оставляет существующий непустой Part Number без изменения;
- переносит центр минимального ориентированного габарита в `(0,0,0)`;
- совмещает продольную ось трубы с `+Z`, ширину с `+X`, высоту с `+Y`;
- по выбору назначает имена вида `40x20x1,5_СтароеИмя_4 шт.ipt`.

Нормализация создаётся одной операцией `TJ_NORMALIZE_TUBE` и отменяется одной
командой Undo. При запуске из IAM команда обходит все уникальные файлы прямых труб,
нормализует локальную геометрию каждого IPT и умножает трансформации всех его
вхождений на обратную матрицу. Поэтому трубы остаются на прежних местах в сборке.
После пересчёта координаты габаритов проверяются с допуском 0,05 мм; при смещении
хотя бы одного вхождения вся транзакция отменяется.

Размеры с погрешностью импорта округляются до десятых миллиметра (`40,01 → 40`),
а нулевой десятичный знак не выводится (`1,0 → 1`, но `1,5 → 1,5`). Последнее
число — количество вхождений конкретного IPT во всей сборке. Перед применением
открывается таблица уникальных деталей с точным и номинальным сечением, толщиной,
количеством, старым и предлагаемым именем. Можно снять выбор с отдельных труб;
нераспознанные детали остаются в таблице с причиной отказа и не изменяются.
Флажок **Переименовать файлы** вынесен отдельно и по умолчанию выключен.
При переименовании сборка переключается на новые имена и сохраняется; прежние IPT
остаются в исходных папках как резервные копии и не удаляются автоматически.
